# Web-Desktop (Windows-11-Look im Browser)
## Entpacken & Hochladen
1. ZIP entpacken (Rechtsklick > Alle extrahieren).
2. Auf github.com ein neues Repository anlegen (public), "uploading an existing file" wählen und ALLE entpackten Dateien (nicht den Ordner selbst) hochladen, committen.
3. Repository > Settings > Pages > Source: "Deploy from a branch", Branch `main`, Ordner `/ (root)` > Save.
4. Nach 1-2 Minuten erreichbar unter `https://DEINNAME.github.io/REPOSITORY/`.
## Öffnen
PC: Link im Browser öffnen. iPad: Link in Safari öffnen; optional Teilen > "Zum Home-Bildschirm".
## Bedienung
Maus: Doppelklick öffnet, Rechtsklick = Kontextmenü. Touch: Doppeltippen öffnet, langes Drücken = Kontextmenü, Fenster am Titelbalken ziehen.
Geheimbefehl im Terminal: `01hacker01` (Ende: ESC oder `stopmatrix`).
## Neu: Downloads & Browser
- Explorer: Ordner `Downloads`, Button „⬇ Herunterladen“ (echter Browser-Download der markierten Datei) und „＋ Datei hinzufügen“ (max. 1,5 MB pro Datei).
- Browser-App: Suche über Wikipedia im Fenster, Adressen als eingebettete Seite (viele Seiten verbieten das), „↗ Neuer Tab“ für Google/andere.
